Detalhes do projeto

O MN-Check nasceu de uma necessidade real de operação: reduzir erros, organizar mapas, validar produtos e registrar histórico de conferência.

Conferência Leitura de códigos CODE 128 e validação de produtos.
Contagem Controle de mapas, itens conferidos e finalizados.
PDF Upload e leitura de arquivos para apoiar o fluxo operacional.
Dashboard Visão geral com dados da operação em tempo real.
